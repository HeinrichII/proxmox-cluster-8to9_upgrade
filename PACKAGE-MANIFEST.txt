REV-4 SAFETY CHANGES
  * Non-quorate or unreadable cluster status is a hard NO-GO.
  * Guest backups must succeed on mounted external storage, and an operator must
    confirm a restore test before GO.
  * Unknown third-party repositories are rejected rather than blindly rewritten.
  * apt update failures and remaining Bookworm sources stop the repository step.
  * Postcheck now fails closed on version, quorum, services, units, apt, or network.
  * Docker is recreated using its current deb822 source and vendor keyring format.
  * Unsupported UI/APT customizations remain outside the validated procedure.

HARD GATES
  * Ceph absent (confirmed). Pre-flight stops if it isn't.
  * Cluster healthy and quorate.
  * External guest backups successful and one restore tested.
  * pve8to9 --full must show 0 FAIL before repo swap.
  * No unknown enabled third-party repository.
  * apt update after swap must be error-free before dist-upgrade.
  * Postcheck must exit 0 before touching the next node.
  * NO downgrade from 9 -> 8. Node 1 first = safe canary.
